Parameter Inconsistency Audit v1.7.0 — Windows folder app
==================================================

This package is a FOLDER (not a single packed exe). Extract it, then run
ParameterAudit.exe inside the extracted folder.

License (required) — easy load
------------------------------
You do NOT have to rename the file. Put any of these next to ParameterAudit.exe:
  ParameterAudit.lic
  ParameterAudit.json
  ParameterAudit.txt
  Owner_ParameterAudit_7day.txt  (or any .lic / .json / .txt license)

Or click **Load license file…** and pick the downloaded file.

To CREATE a license (owner):
  1. Open LicenseGenerator\LicenseGenerator.exe
  2. Type Days of license (for example 7)
  3. Click Generate license
  4. Copy the generated ParameterAudit.lic / .json / .txt next to ParameterAudit.exe


Three folders (created next to the .exe)
----------------------------------------
  Input\
    5G\    5G / NR dumps
    4G\    4G / LTE dumps
    3G\    3G dumps
    2G\    2G dumps
  Reference\   recommended / plan values
  Output\      all inconsistency reports

How to run
----------
1. Extract ParameterAudit_Windows_v1.7.0.rar to any drive (for example D:\ParameterAudit).
2. Put dumps into the matching Input network folder:
     Input\5G   Input\4G   Input\3G   Input\2G
     - Any file names; more than one file; no file-count limit
     - Any number of sheets; any number of columns
     - 4G Cell sheet maps Local cell ID to L09/L18/L21/L26; only that sheet is read for 4G bands
     - 5G NRDUCELL sheet maps NR DU Cell ID to the NR band; only that sheet is read for 5G bands
3. Put every recommended / plan-value workbook into Reference\
     - Always include these three columns: MML Object, Parameter ID, Parameter Name
     - Parameter Name = dump display name (used to find the field in Input)
     - Parameter ID may be SwitchName@Attribute (before @ = switch, after @ = parameter)
     - Proposed / Recommended / Plan value columns are detected automatically
     - Direct recommended values (1, ON, -108) are compared as the whole parameter
     - Switch/bit recommended values (GeranCsftbSwitch-1 or A-0&B-1) are searched inside the Parameter Name column of the dump; other packed options in that cell are ignored
     - Band/group conditions such as L9:-74 L18:-118 or (InterFreqHoGroupId=1)=>L09=-108 are applied per cell
4. Put a license file next to ParameterAudit.exe (.lic or .json or .txt). No rename required.
   Or click Load license file… and pick the file.
5. Double-click ParameterAudit.exe
6. Tick 5G / 4G / 3G / 2G — only those Input folders are searched
7. Click **Generate Report** (always shown at the bottom of the window)
8. Reports are written to the Output folder (and opened if you choose)

You can also Browse this PC and point the app at folders that already exist
somewhere else. Files stay on this PC. Nothing is uploaded. There is no
file-size limit from the app.

Supported files: .xlsx  .xlsb  .xlsm
Excel 97-2003 .xls is not read; save as .xlsx first.

Limits (note)
-------------
Microsoft Excel itself allows 1,048,576 rows and 16,384 columns per sheet.
This tool does not add a lower cap on files, sheets, or columns.
Very large dumps need more RAM and take longer.

Windows Defender
----------------
The app is unsigned. If Windows blocks it: More info → Run anyway,
or add the extracted folder as an exclusion. Use the extracted FOLDER,
not a single packed exe.
