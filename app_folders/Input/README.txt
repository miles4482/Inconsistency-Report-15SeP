Put configuration dumps in the network subfolders:

  Input\5G     5G / NR dumps
  Input\4G     4G / LTE dumps
  Input\3G     3G dumps
  Input\2G     2G dumps

In the tool, tick 5G / 4G / 3G / 2G. Only those folders are searched.

Any file names. More than one file. Any number of sheets and columns.
Sheet names that match an MO / MML Object are treated as that object.
Supported: .xlsx  .xlsb  .xlsm
