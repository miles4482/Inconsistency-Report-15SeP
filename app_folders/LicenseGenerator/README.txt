# License Generator (owner)

1. Open `LicenseGenerator.exe`.
2. Type **Days of license** (example: 7, 14, 30).
3. Click **Generate license**.
4. Copy `ParameterAudit.lic` or `ParameterAudit.txt` or `ParameterAudit.json`
   into the same folder as `ParameterAudit.exe`.

Keep `parameter_audit_private.key` in this folder. Do not give this generator
folder to people who should only run ParameterAudit.
